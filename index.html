架设、对中整平、设站

  1. 架头大致水平、三脚架踩实；仪器轻放，立即拧紧连接螺旋。
  2. 用光学或激光对中器对准测站点，偏差控制在 1–2 mm；先圆气泡粗平，再管气泡精平。
  3. 开机检查电量、棱镜常数、温度气压改正和倾斜补偿。
  4. 输入测站与后视点；照准后视方向，在仪器里配置后视度盘。
  5. 确定测回数：第 1 测回盘左起始读数约 0°，之后每测回按 180°/n 置盘。
  6. 后视定向完成后，再进入第 1 测回盘左观测。

    作业流程与公式
    
        
      
    
      
    
        
    流程
    
        
    架设 → 对中 → 整平 → 开机检查 → 设站（测回数）→ 后视定向 → 第 1 测回盘左 → 同测回盘右 → 置盘 → 下一测回盘左 → 盘右 → 成果检核。
    
        
    一个测回 = 一个盘左半测回 + 一个盘右半测回，不能连续测两个盘左。测回之间按 180°/n 置盘：2 测回为 0°、90°；3 测回为 0°、60°、120°；4 测回为 0°、45°、90°、135°。
    
        
    公式
    
        
    半测回：βL=bL−aL，βR=bR−aR；一测回：β=(βL+βR)/2；各测回平均：Σβ/n。
    
        
    2C = L − (R ± 180°)；2C 互差 = 各方向 2C 的最大值 − 最小值。
    
        
    限差
    
        
    DJ6：半测回角值互差 40″，各测回角值互差 24″，2C 互差按教材不作要求。DJ2：半测回 20″，各测回 12″，2C 互差 13″。限差随规范版本和等级变化，以现行规范与指导教师要求为准。
    
        
    操作
    
        
    点读数格子或距离框，用底部数字键盘。度按 → 到分；分、秒满两位自动跳；秒满后自动到距离框；距离输入后按 → 下一条。
